# Godot 2D Game

一个使用 Godot 4 和 GDScript 开发的 2D 游戏项目。

## 项目简介

本项目是一个独立游戏开发实践项目，主要探索 2D 游戏中的战斗系统、敌人 AI、伤害判定以及回合制行动机制。

项目目前处于早期开发阶段，持续完善中。

## 已实现功能

- **敌人系统**：敌人生成、波次管理和属性成长。
- **伤害判定**：头部与身体独立碰撞检测，不同部位受到不同伤害。
- **伤势系统**：正常、轻伤、重伤和死亡四种状态。
- **敌人属性**：等级、枪法、移动速度等基础属性。
- **玩家战斗系统**：行动力分配、攻击和闪避选择。
- **闪避判定**：连续判定条机制，不同敌人具有不同判定难度。
- **玩家状态**：三颗心的生命状态显示及伤势恢复机制。
- **Boss机制**：支持特殊敌人属性和伤害规则。

## 技术栈

- Godot Engine 4
- GDScript
- 2D Physics
- Godot Scene System

## 运行方式

1. 下载或克隆本仓库。
2. 使用 Godot 4 打开 `project.godot`。
3. 运行 `Main.tscn` 开始测试。
